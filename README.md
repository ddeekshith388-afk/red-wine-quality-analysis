Red Wine Quality Analysis Using Linear Regression

Project Overview

This project focuses on exploring and analysing a red wine quality dataset using Python and applying Linear Regression to study relationships between input features and the target variable.

Objectives

- Explore and understand the dataset.
- Identify missing values and duplicate records.
- Visualize data distributions and correlations.
- Prepare features and the target variable for model training.
- Split the dataset into training and testing sets.
- Build a Linear Regression model and examine its summary.

Technologies Used

- Python
- Pandas
- Data Visualization
- Correlation Analysis
- Heatmap
- Scikit-learn
- Linear Regression
- Jupyter Notebook

Project Workflow

1. Imported the required Python libraries.
2. Loaded and explored the dataset using "head()", "tail()", "shape", "columns", "describe()", and "info()".
3. Checked for missing values and duplicate records.
4. Removed duplicate records.
5. Performed data visualization and correlation analysis using a heatmap.
6. Separated the input features ("X") and target variable ("y").
7. Split the dataset into training and testing sets.
8. Implemented Linear Regression and examined the model summary.

Project File

- "wine&red.ipynb" — Jupyter Notebook containing the analysis and model implementation.

Key Learning Outcomes

- Understanding dataset exploration and preprocessing.
- Analysing relationships between numerical variables.
- Preparing data for machine learning.
- Understanding training/testing splits and Linear Regression.
